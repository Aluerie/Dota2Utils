# 👻 DotaPlusQuests

This simple script presses the "Refresh challenges" button and cycles over all Dota 2 heroes,
so you don't have to press it for all 120+ heroes yourself.

## 👆 How to use

1. Navigate to any hero loadout page in Dota 2.
2. Run the script with the [dplus_quests.bat](./dplus_quests.bat) shortcut, or:

```sh
uv run DotaPlusQuests
```

You have 2 seconds to switch back to Dota 2. Move the mouse to a screen corner to abort.

Button positions are measured on 2560x1440 and scaled to your resolution, which works best on 16:9 screens.
