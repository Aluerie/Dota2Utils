# 🧰 dota2utils-common

Shared code for the tools in this repository. Not meant to be used on its own.

- `config` - loads the repository's `config.toml`.
- `steam` - finds the Steam install, your Friend ID, the Dota 2 install and its config/guides folders.
- `datafeed` - hero and item lists from Valve's dota2.com datafeed.
- `guides` - finds, creates and saves Dota 2 hero guide (`.build`) files.
- `logs` - console logging with loguru (emoji level icons), including stdlib `logging` from libraries.
